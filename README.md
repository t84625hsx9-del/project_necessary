# Fiz Lab - виртуальная физическая лаборатория

Интерактивные симуляторы школьной физики: маятники, волны, линзы, магниты.
Двигаешь ползунки - рисунок пересчитывается по формулам прямо во время работы.
Ничего не зашито в картинки: каждая линия на экране посчитана.

Сделано на Python: Streamlit (интерфейс), Plotly (рисунки), NumPy (расчёты).

## Что внутри

**🧵 Механика.** Нитяной маятник: период считается точно, через эллиптический
интеграл, а не по школьной формуле - и рядом показано, на сколько процентов
школьная формула ошибается при большом размахе. Бегущая волна: связь длины
волны, частоты и скорости. Пружинный маятник: положение равновесия по k·x = m·g,
период 2π√(m/k).

**🔦 Оптика.** Преломление и полное внутреннее отражение: угол выхода считается
законом Снеллиуса на всех углах, включая крайние 0° и 90°. Линзы: построение
изображения тремя лучами для собирающей и рассеивающей, формула тонкой линзы,
пять школьных случаев и мини-тест.

**🧲 Магнетизм.** Взаимодействие полосовых магнитов, правило левой руки (сила
Ампера), правило правой руки для прямого проводника и для соленоида, правило
Ленца с индукционным током в кольце - с двух ракурсов сразу.

## Как запустить

Нужен Python 3.11. Один раз создать окружение и поставить библиотеки:

```
cd project_necessary
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Дальше каждый раз:

```
cd project_necessary
.venv/bin/streamlit run main.py
```

Откроется в браузере на localhost. Остановить - Ctrl+C в терминале.
